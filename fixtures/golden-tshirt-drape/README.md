# Golden T-Shirt drape v1

Synthetic drape fixture of the module `3d` (catalog §3.9.1, §4.6; draft `0.3.0`, design decision ADR-029), built on the [Golden T-Shirt v1](../golden-tshirt/README.md) and the [Golden T-Shirt 3D v1](../golden-tshirt-3d/README.md). Every file in `v1/` is generated by `tools/oracle/golden-tshirt-drape.mjs` and listed in `v1/manifest.json`; this description lives outside the fixture directory because the manifest allows no unlisted file inside it.

## Content

- **Two synthetic bodies** in one size system (`art_golden-drape-body-sizes`, issuer kind `synthetic`, registry `d2p:measurement-definitions` 1.1.0): `body-m` (label M) and `body-l` (label L), each with the six required definitions of the avatar profile `d2p:standard-a-pose` (height, chest, waist and hip girth, shoulder width, arm length) plus neck girth and waist height, as table values with a symmetric uncertainty of ±5 mm.
- **One synthetic body measurement profile with a baseline** (`art_golden-drape-body-profile`, subject `synthetic`, pseudonym "Synthetic figure P", classified `public`): it pins `body-l` as its baseline, copies its values as table values (`method` and source kind `size-table`) and overrides two of them, chest girth and arm length, with self-measured values.
- **One garment per T-shirt size** (`size-a`, `size-b`): the 3D fixture garment r1 of that size (same pattern evaluation reference, four panel instances, sewing bindings, woven material assignment and flat-lay arrangement), copied rather than pinned, plus two **body bindings** (`body-m` on the size entry, `body-profile` on the profile; avatar profile `d2p:standard-a-pose`, pose `d2p:a-pose`) and two **simulation configurations** (`drape-body-m`, `drape-body-profile`: size `eval-main`, start arrangement `flat-lay`, solver profile `d2p:fit-approximation`, material physics `d2p:cotton-woven` for the woven assignment, seed 1).
- **Expected body models** (`expected/body-models/`): for each body the expected status (`succeeded`), every control-measure target with its origin (`size-table`, `profile` for the two overrides, `inferred` for the derived definitions without a source value) and the tolerance of the avatar profile. Body meshes are not expected results.
- **Expected size comparison** (`expected/drapes/size-comparison.json`): on both bodies, at the chest and the waist, the mean clearance of the size A drape is less than that of the size B drape. It is a metamorphic expectation that every credible solver reproduces, not an expected drape: no vertex, pixel or exact value is expected.
- **Negative fixtures** (`negative/<name>/`, each with its `case.json`): a baseline size that does not exist, a table value that differs from the baseline, a succeeded body model of a source without height, a configuration without body binding, a knit material physics profile on a woven assignment, and a body model of an individual profile without `personalDerived`.

The bodies are chosen so that T-shirt size A fits closer than size B on both of them: their chest girths lie below the chest girths of both garment sizes, and size B is wider than size A. The values are **synthetic test data, not a size table or a norm**; the standard publishes no size table (catalog §5).

The drape chain itself (body model snapshot, rest and draped meshes, drape scene, simulation report, fit map) is in the conformance cases `conformance/<level>/golden-tshirt-drape/`, for a synthetic and for a personal body. Those meshes and fit maps are synthetic, deterministic document-level test data for the kernel-free checks, not the result of a solver. The body mesh is a torso and two legs made of ring stacks whose perimeters and heights are the measured girths and heights (below the hip nothing is wider than the hip); it has no arms, so arm length and shoulder width are given by landmarks only, and the upper-arm, wrist and underbust girths, back width, back length and shoulder length are not represented on it.

## Profiles

All profiles the fixture pins are **provisional** (draft `0.3.0`): the avatar profile `d2p:standard-a-pose`, the solver profile `d2p:fit-approximation`, the material physics profile `d2p:cotton-woven` (the negative fixture `material-class-mismatch` also uses `d2p:cotton-jersey`, listed in the manifest's external files), the mesh profile `d2p:drape-coarse` and the tolerance profile `d2p:golden-tshirt-drape` (body control measures 5 mm, penetration 3 mm, seam gap 2 mm, rest-mesh planar deviation 0.5 mm). Their values are proposals, not calibrated against anthropometric data or fabric samples, and a comparison against them is not benchmark evidence until a maintainer decision freezes them.

## Open review

The bodies, the bindings and the size comparison still need the domain review by a pattern maker or seamstress (QEV-016, `review.status: "pending"`). Nothing here claims a calibrated body, a realistic drape or a fit.
