# Golden T-Shirt 3D v1

Synthetic 3D fixture of the module `3d` (catalog §3.9, §4.5), built on the [Golden T-Shirt v1](../golden-tshirt/README.md). Every file in `v1/` is generated by `tools/oracle/golden-tshirt-3d.mjs` (`npm run oracle:3d`) and listed in `v1/manifest.json`; this description lives outside the fixture directory because the manifest allows no unlisted file inside it.

## Content

- **One garment per size** (`size-a`, `size-b`), each pinning the `regular-woven` evaluation of pattern r1 with its geometry snapshot digest.
- **Four panel instances**: `panel-front`, `panel-back`, and `panel-sleeve-left` / `panel-sleeve-right`, two instances of the one `sleeve` piece (cut instances `sleeve-left` and `sleeve-right`; the right one is mirrored by its cut instance).
- **Twelve sewing bindings**: one per seam connection of the pattern (interfaces in the connection's order, each bound to the panel of its cut instance) and one per armhole sewing group. The garment copies no seam semantics; it references the pattern's elements.
- **One material assignment** (woven, with a display colour) and **one arrangement**, `flat-lay`: front at z = +120 mm, back turned 180° about +Y at z = -120 mm, sleeves at z = 0 beside the body (left sleeve at +X, the wearer's left).
- **Scene inputs** with their evaluation keys, and **scene expectations**: the panel bindings with their scene transforms in metres, the twelve seam bindings, twenty control measures (interface lengths in mm from the 2D snapshot and in m, × 0.001), the contour-start anchors in the scene and the expected `bindingsDigest`.
- **Change case**: both garments rebind to pattern r2 (bust-ease +20 mm, sleeve-length +30 mm). Element IDs and the arrangement stay; evaluation pins, evaluation keys and bindings digests change.

Meshes are not expected results: mesh digests depend on the backend and the mesh profile. Implementations compare their meshes with the pinned tolerance profile `d2p:golden-tshirt-3d` 1.0.0 (metric `d2p:mesh-planar-deviation`), and their scene bindings with the expectations exactly (catalog §3.4 numeric comparison). The tolerance profile and the mesh profile `d2p:golden-tshirt-3d-preview` 1.0.0 are `frozen` (maintainer decision 2026-10-25, values unchanged).

The case `conformance/semantic/golden-tshirt-3d/scene-snapshot-preview.case.json` adds a complete arrangement scene snapshot of r1 size A with four boundary-sampled panel meshes and its glTF view (`scene.gltf`: one node per panel instance, metres, Y up, `sceneDigest` in `asset.extras.d2p`) for import tests with independent viewers.

## Open review

The arrangement is a deterministic flat lay for previews, not a drape or a fit statement. Orientation, sides and bindings still need the domain review by a pattern maker or seamstress (QEV-016, `review.status: "pending"`). All values are synthetic test data.
