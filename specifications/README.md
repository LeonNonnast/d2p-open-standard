# specifications/

Normative prose of the standard: document identity, coordinate system and units, semantics of pattern elements, extension namespaces and fallbacks, conformance profiles, versioning and compatibility rules, and the standards gap analysis (which existing standards were considered and why they do not cover the required semantics).

RFCs for normative changes live in `specifications/rfcs/` (see [GOVERNANCE.md](../GOVERNANCE.md)). No specification text has been published yet.
